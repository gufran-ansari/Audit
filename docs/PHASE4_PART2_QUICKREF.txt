🎯 NOINDEX AUDIT
--------------------------------------------------------------------------------

DETECTS:
- <meta name="robots"> tags
- noindex / index directives
- nofollow / follow directives

STATUSES:
PASS    → Indexable (no noindex)
WARNING → Mixed directives
FAIL    → Noindex found
ERROR   → Fetch failed

STORED DATA:
{
  "robots_content": "noindex, nofollow",
  "index_status": "noindex",
  "follow_status": "nofollow"
}

--------------------------------------------------------------------------------
🎯 FAQ SCHEMA AUDIT
--------------------------------------------------------------------------------

DETECTS:
- FAQPage schema in JSON-LD
- FAQ content patterns
- Structured FAQ data

STATUSES:
PASS    → Schema found
WARNING → Content but no schema
FAIL    → Nothing found
ERROR   → Fetch failed

STORED DATA:
{
  "schema_found": true,
  "schema_type": "FAQPage",
  "schema_count": 5,
  "content_found": true
}

--------------------------------------------------------------------------------
⚙️ HOW IT WORKS
--------------------------------------------------------------------------------

USER FLOW:
1. User navigates to project.php
2. Switches to URLs tab
3. Selects audit modules (checkboxes)
4. Clicks "Run Selected Audits"
5. Confirms in dialog
6. System runs audits sequentially
7. Results appear in table columns

EXECUTION FLOW:
1. JavaScript: runSelectedAudits()
2. JavaScript: runProjectAudit('noindex')
3. PHP: NoindexAuditController->handle()
4. PHP: NoindexAuditService->auditProject()
5. PHP: NoindexAuditProcessor->analyzeRobots()
6. PHP: NoindexAuditRepository->save()
7. Database: INSERT/UPDATE page_audit_results
8. JavaScript: loadPages() (refresh table)
