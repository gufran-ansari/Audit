--------------------------------------------------------------------------------
⚙️ HOW IT WORKS
--------------------------------------------------------------------------------

LOREM AUDIT FLOW:
1. Fetch page HTML
2. Remove scripts/styles
3. Extract text content
4. Search for keywords (case-insensitive)
5. Count occurrences
6. Extract context snippets
7. Return PASS/FAIL/ERROR

STAGING AUDIT FLOW:
1. Fetch page HTML
2. Search links (regex extraction)
3. Search images (regex extraction)
4. Search scripts (regex extraction)
5. Search stylesheets (regex extraction)
6. Search canonical tags (regex extraction)
7. Match URLs against patterns
8. Deduplicate and count
9. Return PASS/FAIL/ERROR
