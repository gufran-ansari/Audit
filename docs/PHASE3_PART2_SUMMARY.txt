================================================================================
  IMPORT PROCESS FLOW
================================================================================

STEP 1: Validate Sitemap
→ Check sitemap exists and is validated
→ Determine sitemap type (sitemap vs sitemap_index)

STEP 2: Extract URLs
→ Fetch sitemap XML (60s timeout)
→ Use XMLReader for streaming parse
→ Extract <loc> elements from <url> or <sitemap>
→ No full-file loading

STEP 3: Process Each URL
→ Validate URL format
→ Normalize URL (lowercase, remove params, etc.)
→ Generate SHA256 hash
→ Check if duplicate exists
→ Add to batch insert array

STEP 4: Batch Insert
→ Insert 100 URLs at a time
→ Use transaction for safety
→ ON DUPLICATE KEY UPDATE last_seen_at
→ Count imported, duplicates, invalid

STEP 5: Update Statistics
→ Update sitemap total_urls
→ Update project URL count
→ Return import report

FOR SITEMAP INDEX:
→ Extract nested sitemap URLs
→ Create nested sitemap entries
→ Recursively import from each
→ Aggregate statistics

================================================================================
  DATABASE TABLE STRUCTURE
================================================================================

project_pages:
- id                  INT (primary key)
- project_id          INT (foreign key to projects)
- sitemap_id          INT (foreign key to sitemaps, NULL if manual)
- original_url        VARCHAR(2000) - as found in sitemap
- normalized_url      VARCHAR(2000) - cleaned version
- url_hash            CHAR(64) - SHA256 of normalized URL
- page_status         ENUM (pending, processing, completed, failed, skipped)
- first_discovered_at TIMESTAMP - when first imported
- last_seen_at        TIMESTAMP - updated on re-import
- created_at          TIMESTAMP
- updated_at          TIMESTAMP

INDEXES:
- Unique: (project_id, url_hash) - prevents duplicates
- Index: project_id, sitemap_id, url_hash, page_status
- Foreign Keys: CASCADE delete with projects, SET NULL on sitemap delete

================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: URLs not importing
FIX:
  - Check sitemap is validated
  - Verify sitemap contains <url> elements
  - Check database connection
  - Review PHP error logs

ISSUE: High duplicate count
FIX:
  - Normal when re-importing
  - Check last_seen_at updated
  - Verify urls aren't truly new

ISSUE: Import timeout
FIX:
  - Increase PHP max_execution_time
  - Check server timeouts
  - Reduce batch size if needed
  - Large sitemaps take time

ISSUE: Memory exhausted
FIX:
  - Should not happen with XMLReader
  - Check PHP memory_limit
  - Verify batch processing working
  - Review logs for issues

ISSUE: Statistics not updating
FIX:
  - Check foreign keys intact
  - Verify transaction committed
  - Refresh project page
  - Check repository queries
