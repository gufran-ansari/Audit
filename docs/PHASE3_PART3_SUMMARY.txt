6. ✅ Multi-Sitemap Management
   - Database fields: sitemap_status, last_imported_at

   - Sitemap action buttons (disable/enable/delete)
   - Import button shows based on status

7. ✅ Smart Reimport Logic
   - Detects new URLs → inserts as active

8. ✅ URL Status System

9. ✅ Performance Optimizations

    - Success notification with counts

DATABASE SCHEMA:
----------------

project_sitemaps table:
- sitemap_status ENUM('active', 'disabled') - Control imports
- last_imported_at TIMESTAMP - Track last import time

project_pages table:
- url_status ENUM('active', 'disabled', 'removed', 'pending_audit')
- Indexes on project_id, sitemap_id, url_hash, page_status, url_status
