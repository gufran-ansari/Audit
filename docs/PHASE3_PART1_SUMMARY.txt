================================================================================
  DISCOVERY WORKFLOW DETAILS
================================================================================

STEP 1: robots.txt Discovery
→ Tries: https://domain.com/robots.txt
→ Falls back: http://domain.com/robots.txt
→ Parses: Sitemap: entries
→ Returns: array of sitemap URLs

STEP 2: Common Locations (if robots.txt fails)
→ Checks: /sitemap.xml
→ Checks: /sitemap_index.xml
→ Checks: /sitemap1.xml
→ Checks: /sitemap-index.xml
→ Tries HTTPS first, then HTTP
→ Stops after first successful find

STEP 3: XML Validation
→ Fetches sitemap content (30s timeout)
→ Validates XML structure
→ Checks for parse errors
→ Returns detailed error messages

STEP 4: Type Detection
→ Has <sitemap> elements? → sitemap_index
→ Has <url> elements? → sitemap
→ Root is <urlset>? → nested_sitemap
→ Otherwise? → invalid

================================================================================
  SITEMAP STATUSES
================================================================================

DISCOVERED: Initial state after finding sitemap
VALIDATED:  Sitemap is valid and contains URLs
INVALID:    XML is malformed or not a sitemap
UNREACHABLE: URL cannot be accessed

================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: No sitemaps discovered
FIX: 
  - Check domain is accessible
  - Try manual addition
  - Verify robots.txt exists
  - Check common sitemap locations manually

ISSUE: Sitemap shows as "Invalid"
FIX:
  - Check XML structure
  - Validate against sitemap.org schema
  - Ensure proper namespace
  - View sitemap in browser

ISSUE: Sitemap shows as "Unreachable"
FIX:
  - Verify URL is correct
  - Check HTTPS vs HTTP
  - Test URL in browser
  - Check server firewall

ISSUE: Duplicate sitemap error
FIX:
  - Sitemap already exists for this project
  - Delete existing sitemap first
  - Or use a different URL
