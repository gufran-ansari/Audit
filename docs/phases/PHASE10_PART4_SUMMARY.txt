BUGS FIXED:
===========

1. CRITICAL: Missing getPdo() method on Database class
   - PageRepository.batchInsert() called $this->db->getPdo()
   - PageRepository.getByIds() called $this->db->getPdo()
   - PageRepository.bulkUpdateStatus() called $this->db->getPdo()
   - RetryJobProcessor called $db->getPdo()
   - Method did not exist — would cause fatal error at runtime
   - FIX: Added getPdo() as alias for getConnection()

2. SECURITY: Session fingerprint validation was no-op
   - SecurityService::validateFingerprint() was called in bootstrap
   - But return value was ignored — hijacked sessions continued working
   - FIX: Added conditional to destroy session on fingerprint mismatch

3. SECURITY: Internal database IDs exposed on public report
   - report.php passed raw $pages array (including pp.id) to JSON
   - Public clients could see internal auto-increment IDs
   - FIX: Strip 'id' key before JSON encoding for public page

4. SECURITY: API login blocked by overly strict isAjax() check
   - routes/auth.php api_login action required X-Requested-With header
   - Legitimate JSON API calls (fetch, curl) would fail
   - FIX: Removed isAjax() requirement, keep POST-only check

5. SECURITY: No .htaccess protection on storage/config/database dirs
   - Root .htaccess blocked access, but if misconfigured, dirs were exposed
   - FIX: Added individual "Deny from all" .htaccess in each sensitive directory
