INTEGRATION GUIDE:
==================
From any module, use static helpers:
  DashboardService::logActivity('audit_started', 'H1 audit started', $projectId);
  DashboardService::notify('audit_complete', 'Audit finished', 'All pages processed', $userId);

From frontend:
  Dashboard.init()              — Bootstraps search, notifications, dark mode
  Dashboard.loadOverview(el)    — Renders full dashboard into container
  Dashboard.showToast(msg, type) — Shows toast notification
  Dashboard.search(query)       — Triggers global search
