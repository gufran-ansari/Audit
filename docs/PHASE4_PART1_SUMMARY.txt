H1 AUDIT LOGIC:
---------------

Statuses:
- PASS: Exactly 1 H1 tag found
- WARNING: Multiple H1 tags found (stores first H1)
- FAIL: No H1 tag found
- ERROR: Page could not be fetched or parsed

Data Stored:
- h1_count: Number of H1 tags
- h1_text: Text of first H1 (or null)
- h1_tags: Array of all H1 texts
- error: Error message if status is ERROR

META AUDIT LOGIC:
-----------------

Extracts:
- Page title (from <title> tag)
- Meta description (from <meta name="description">)
- OG image (from <meta property="og:image">)

Title Validation:
- missing: No title found → contributes to FAIL
- too_short: < 30 chars → contributes to WARNING
- too_long: > 60 chars → contributes to WARNING
- valid: 30-60 chars → contributes to PASS

Description Validation:
- missing: No description found → contributes to FAIL
- too_short: < 120 chars → contributes to WARNING
- too_long: > 160 chars → contributes to WARNING
- valid: 120-160 chars → contributes to PASS

Overall Status:
- PASS: Both title and description valid
- WARNING: Either title or description has length issues
- FAIL: Either title or description missing
- ERROR: Page could not be fetched

Data Stored:
- title, title_length, title_status
- meta_description, description_length, description_status
- og_image
- error

API USAGE:
----------

Audit Single Page:
POST /routes/h1_audit.php?action=audit_page
Body: page_id=123

Audit Multiple Pages:
POST /routes/h1_audit.php?action=audit_pages
Body: page_ids[]=[123,456,789]

Audit Entire Project:
POST /routes/h1_audit.php?action=audit_project
Body: project_id=1

Get Results:
GET /routes/h1_audit.php?action=results&project_id=1

Get Stats:
GET /routes/h1_audit.php?action=stats&project_id=1

Delete Result:
POST /routes/h1_audit.php?action=delete&page_id=123

(Same endpoints available for meta_audit.php)

ERROR HANDLING:
---------------

Timeout:
- cURL timeout set to 30 seconds
- Returns ERROR status with timeout message

Unreachable URL:
- HTTP status code check (200-399 success)
- Returns ERROR status with HTTP code

Invalid HTML:
- DOMDocument with error suppression
- Handles malformed HTML gracefully
- Returns valid results if parseable

Network Errors:
- cURL error messages captured
- Stored in audit result error field
- Displayed in UI tooltip
