ARCHITECTURE OVERVIEW
================================================================================

AUDIT FLOW WITH NEW ARCHITECTURE:

1. User clicks "Run Selected Audits"
   ↓
2. Frontend creates audit run via API
   - AuditRunService::createRun()
   - Returns run UUID and ID
   ↓
3. Frontend starts audit execution
   - AuditRunService::startRun()
   - Status: pending → running
   ↓
4. For each page:
   a. Module processes page
   b. Returns standardized result (AuditResultService)
   c. Check for changes (AuditHistoryService)
   d. Save result with run_id
   e. Record history if changed
   f. Update run progress
   ↓
5. Frontend completes run
   - AuditRunService::completeRun()
   - Status: running → completed
   - Calculate execution time
   ↓
6. Frontend displays results
   - Summary statistics
   - Individual page results
   - Change indicators

DATA FLOW:

Module Processor
  ↓
AuditResultService::createResult()
  ↓
Module Repository::save()
  ↓
AuditHistoryService::recordIfChanged()
  ↓
Database (audit_results + history)
  ↓
Frontend Display
